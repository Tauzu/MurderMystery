## 1. 用語定義

| 用語 | 意味 |
|---|---|
| ミステリー／シナリオ | 投稿者が作成する1本の事件。冒頭文・キャラ・状況文・手札・結末文で構成される |
| キャラクター | シナリオ内の登場人物（4人固定。うち1人が犯人） |

| 席 | ルーム内のキャラクターに対応する参加枠。人間かNPCが座る |
| NPC | 生成AIが操作する席 |
| 探偵側 | 犯人以外の3キャラクター |

## 4. ゲームルール詳細

### 4.1 構成

- 1ルーム＝4席。各席に1キャラクターが対応する。
- 4席のうち1キャラクターが犯人。どのキャラクターが犯人かはシナリオで固定。
- 席とキャラクターの対応は、**ルーム作成時にランダム**で割り当てる。犯人役も同様にランダムとなる。

### 4.2 進行フェーズ

| # | フェーズ | 内容 | 時間 |
|---|---|---|---|
| 1 | 導入 | 冒頭文を全員に表示 | 読了後に全員の「次へ」または最大60秒【仮】 |
| 2 | 確認 | 自分のキャラクター・状況文・手札4枚を確認 | 最大3分【仮】。全員が「準備完了」で短縮 |
| 3 | セット1 | 手札公開→2人1組の会話 | 公開30秒＋会話10分 |
| 4 | セット2 | 同上（組み合わせを変える） | 同上 |
| 5 | セット3 | 同上（組み合わせを変える） | 同上 |
| 6 | 投票 | 犯人を1人選ぶ | 2分 |
| 7 | 結末・感想戦 | 結果と結末文を表示。全員での会話（感想戦）ができる | 制限なし |

合計：約40〜45分。

### 4.3 手札の公開

- 各セットの開始時、**全員が手札のうち未公開の1枚を選ぶ**。制限時間は30秒。
- 全員が選択した、または時間切れとなった時点で**4枚を同時に公開**する。
- 時間切れで未選択の場合は、**未公開の手札からランダムに1枚**を自動で公開する。
- 公開されたカードは、以降のゲーム画面の「公開済みカード」欄に残る。
- カードの内容は**原則として事実**である。ただし全16枚のうち**1枚だけ捏造カード**（嘘の内容）がある（4.3.1）。
- 公開しなかった手札は本人のみが閲覧でき、他者には最後まで見えない（結果画面で開示）。
- 3セットを終えると、1人あたり3枚が公開され、1枚が非公開のまま残る。

### 4.3.1 カードの種類と捏造カード

- 手札は1人につき**目撃証言2枚・証拠品2枚**。目撃証言は、そのキャラクターが見聞きしたこと。証拠品は、物とそこから分かること。種類はカードに表示する。
- 全16枚のうち**1枚だけが捏造カード**。捏造カードがあることは、ルールとして全員に知らせる（どれが捏造か、誰が持っているかは知らせない）。
- 捏造カードは、**犯人の手札にも、探偵側の手札にも**入れられる。どちらにするかはシナリオで決める。
  - 犯人が持つ場合：犯人が自分で作った嘘（偽のアリバイの証言、偽装した証拠品など）。犯人は公開するかどうか、いつ公開するかを選べる。捏造を見破ることは、持ち主＝犯人を突き止めることと同じになる。
  - 探偵側が持つ場合：犯人が仕込んだ偽の証拠品や、犯人から聞かされた嘘の話など。持ち主は捏造だと知らず、真実だと信じている。見破った後に「誰が仕込めたか、誰が得をするか」を詰める推理が残る。
- 捏造カードであることは、**犯人の画面でだけ**表示する。探偵側が持つ場合も、犯人には**最初から、誰のどのカードが捏造か**を表示する（犯人が仕込んだものなので）。持ち主を含め、他の人には普通のカードと見分けがつかない。
- 公開されなかった場合、捏造カードは推理に使われないまま終わる。それでもよい。
- 捏造カードは、他の真実のカードと矛盾するように作る（6.2.1）。矛盾を見つけ、どちらが捏造かを突き止めることが推理の中心になる。
- 結果画面で、どのカードが捏造だったかを開示する（4.7）。

### 4.4 会話（チャット）

- 形式はテキストチャット。プレイ中は、**2人1組の会話**だけを行う（4人分の発言が同時に流れて読みづらいため。2026-10-14 の変更）。
- 組み合わせはセットごとに変わり、3セットで全員が他の3人と1回ずつ話す。席番号を 0〜3 とすると、セット1は 0-1・2-3、セット2は 0-2・1-3、セット3は 0-3・1-2。席の割り当てはランダムなので、誰と誰かは毎回変わる。
- **会話は組の2人にしか見えない**。他の組の会話は、プレイ中は見えない。公開カードだけが全員にとっての事実で、会話で得た情報を他の人に伝えるかどうかは各自の判断（嘘も、犯人のみ許される）。
- 4人での会話は、**結果が出た後の感想戦**でのみ行う（4.7）。
- 1メッセージは最大200文字【仮】。連続投稿は1秒あたり1件まで【仮】。
- 会話中は、公開済みカードと自分の状況文・手札をいつでも参照できる。
- セット終了時にタイマーが0になった時点で、会話は自動的に締め切る。早期終了は、**全員が「話し終えた」に同意した場合のみ**可能。

### 4.5 発言ルール

- 犯人のみ嘘をついてよい。
- 犯人以外は、**自分の状況文・手札に反する事実を述べてはならない**。ただし、秘密を言わないことは可能。自分の手札が捏造カードだった場合も、本人は知らないので、それに沿って話すことは嘘にあたらない。
- 公開されたカードを「捏造ではないか」と疑う発言は、誰でもしてよい。
- 上記は規約・ルール表示で周知するものであり、システムによる自動判定は行わない。ただし**NPCはこの制約に従って発言する**。

### 4.6 投票と勝敗

- 全員が、**自分以外の3人**から犯人と思う1人に投票する。
- 時間切れで未投票の場合、その人の票は無効とする（棄権）。
- 最多得票となったキャラクターが犯人である場合：**探偵側の勝利**。
- 最多得票が犯人以外の場合：**犯人の勝利**。
- 最多得票が複数の同数となった場合：**犯人の勝利**（棄権のみで全員0票の場合も同様）。
- 勝敗は、人間のプレイヤーのプレイ履歴に記録される。NPCの席には記録しない。

### 4.7 結末

- 結果画面で、得票数、犯人の正体、勝敗、結末文、**全員の手札4枚**を表示する。手札では**捏造カードを明示**する。
- 結果画面では、プレイ中は見えなかった**他の組の会話**も読める。
- 結果が出た後は、**4人全員で会話（感想戦）**ができる。NPCは感想戦では発言しない（AIコスト防止）。
- 結果画面を閉じた時点で、そのシナリオはプレイヤーにとって「プレイ済み」となる（7.3）。

## 5. NPC仕様

### 5.1 NPCの役割

- 4席のうち人間が埋めきれない席をNPCが担当する。
- NPCは割り当てられたキャラクターとして、**会話・手札公開・投票**を行う。

### 5.2 NPCの入力情報（秘匿の原則）

NPCに与える情報は、**そのNPCのキャラクターが知り得る範囲のみ**とする。

| 与える | 与えない |
|---|---|
| 冒頭文、自キャラの状況文と手札4枚、公開済みカード、自分が参加した2人1組の会話、捏造カードが1枚あるというルール | 他の組の会話、他キャラの状況文・非公開の手札、シナリオ全体の真相（ただし**犯人NPCは自分が犯人であること**、自分の行動の真実、**どのカードが捏造か**は与える） |

### 5.3 NPCの振る舞い

- **発言頻度**：1人あたり平均で30〜60秒に1回程度【仮】。直前の発言への返答を優先する。連続発言を避ける。
- **発言内容**：1発言は最大100文字【仮】。キャラクターの口調を保つ。
- **手札公開**：未公開の手札から、状況に応じて選ぶ。犯人NPCは自分に不利なカードを可能な限り後に回す。犯人NPCが捏造カードを持つ場合は、疑いをそらすのに役立つ時点で公開する（公開しない選択も可）。探偵側NPCは、捏造を知らないので普通のカードとして選ぶ。
- **犯人NPC**：嘘やはぐらかしを許容。公開済みの捏造カードは真実だと言い張る（誰が持っていても）。それ以外の**公開済みカードの事実と矛盾する発言はしない**。
- **探偵側NPC**：嘘はつかない。自分の秘密は、問い詰められるまでは明かさない選択ができる。捏造カードが1枚あることを前提に、公開カード同士や自分の手札との矛盾を探す。自分の手札も捏造の可能性がある（犯人に仕込まれた場合）ことを踏まえて判断する。
- **投票**：公開カードと会話をもとに、疑わしい1人を選ぶ。
- **メタ発言の禁止**：「AIです」「プロンプト」等の発言はしない。ただし、**NPCであることはUI上で他プレイヤーに表示する**（7.4）。

### 5.4 無操作時のNPC切替（F12）

- 人間の席について、以下の状態が**3分間**続いた場合【仮】、その席をNPCに切り替える。
  - 会話中：発言・操作（カード選択、投票、ボタン）がない
  - 切断状態（再接続がない）
- 切替の約30秒前に本人へ警告表示を行う。
- 切替後は、その席は**以後NPCが担当**する。本人は、同じゲーム中は復帰できず、観戦に回る（自分のキャラクターの情報は引き続き閲覧可）。
  - 理由：操作の二重化と、NPCが知った情報の扱いの混乱を避けるため。
- 切替後も、その人の勝敗は**記録するが、離脱として扱う**（8.3）。

## 6. シナリオ投稿仕様

### 6.1 入力項目

| 項目 | 内容 | 制限【仮】 |
|---|---|---|
| タイトル | シナリオ名 | 1〜40文字 |
| 概要 | 一覧表示用の紹介（ネタバレなし） | 1〜120文字 |
| 冒頭文 | 事件の導入 | 100〜1500文字 |
| 被害者（任意） | 名前と簡単な設定（公開用）。登場人物欄に「被害者」として表示する | 名前1〜20文字、設定1〜200文字 |
| キャラクター×4 | 名前、簡単な設定（公開用）、犯人かどうか（1人のみ指定） | 名前1〜20文字、設定1〜200文字 |
| 状況文×4 | キャラクターごとの個別情報 | 各100〜1000文字 |
| 手札×16 | 1キャラクターにつき4枚（目撃証言2枚・証拠品2枚）。カードの種類、タイトル、内容。16枚のうち1枚を捏造カードに指定する | タイトル1〜20文字、内容1〜300文字 |
| 結末文 | 犯人の発表と真相の解説 | 100〜2000文字 |

### 6.2 状態

`下書き → AIチェック → 公開 ⇄ 非公開（通報または投稿者の操作）`

- 下書きは何度でも保存でき、投稿者のみ閲覧可能。
- 公開操作時に **AIチェック**を行う。通過した場合にのみ公開される。
- 公開後の本文編集は不可（プレイ済みの人との整合性のため）。誤りがある場合は**非公開にして新規投稿**する。
- 投稿者は自分のシナリオをいつでも非公開にできる。

### 6.2.1 シナリオ作成の指針（勝敗バランス）

探偵側3人に対して犯人は1人で、探偵側は嘘をつかない（4.5）ため、何も考えずに作ると犯人が不利になる。運営制作シナリオは次の指針で作り、投稿者向けの作成ガイドにも載せる。

- **犯人を直接示す手がかりは、探偵側全体で3〜4枚まで**にする。1人の探偵が2枚以上持たない。
- **探偵側の各キャラクターに、疑われる材料**（動機、機会、証明できない時間のいずれか）を持たせる。犯人以外にも、もっともらしい容疑者がいる状態にする。
- **犯人の手札は、自分を直接不利にするカードを1枚だけ**にする。各セットで1枚ずつ、計3枚を公開する（4.3）ため、不利なカードが2枚あると、犯人は必ず1枚を公開させられる。残りの3枚は、中立・病死説の補強・他者への疑いを誘う事実（捏造カードを含んでもよい）などにする。
- **捏造カードは、真実のカード1枚と直接矛盾する**ように作る。直接矛盾するカードが2枚以上あると多数決で即座に見破られるため1枚にする。矛盾が見つかると「どちらが捏造か」の2択になり、他のカードや状況文で決着できるようにする。捏造は、時刻・場所・物の状態など、他の情報と照合できる内容にする（照合できない捏造は見破れない）。
- 捏造カードは、**犯人への疑いをそらす**内容（犯人のアリバイ、他者を示す証拠など）にする。
- 探偵側に捏造カードを持たせる場合は、**証拠品か、犯人から聞いた話（伝聞）の目撃証言**にする。本人が直接見たことが嘘だと不自然になるため。また、見破った後に犯人へたどり着けるよう、それを仕込めた人物・話した人物の手がかりを残す。
- **時刻は「21:45」のように24時間表記で書く**（「午後九時四十五分」より読みやすいため）。
- **時刻の整合を取る**。全員の状況文とカードを時系列で並べ、矛盾する時刻や行動がないか確認する。
- **探偵側の勝率は50%を目標**にする（許容は40〜60%）。公開前にAI同士の対戦で勝率を測る。NPCの探偵は人間より意見が揃いやすく、勝率が高めに出るため、目安として55〜65%までは許容し、人間のプレイ結果（結果画面の勝敗の記録）がたまったら、それで補正する。測り方は `docs/NPC評価.md` を参照。

### 6.3 AIチェック

| チェック | 内容 | 不合格時 |
|---|---|---|
| 構造チェック | 必須項目の充足、文字数、犯人の指定が1人であること、各キャラクターの手札が目撃証言2枚・証拠品2枚であること、捏造カードの指定が1枚であること | 項目ごとに指摘を表示し修正を促す |
| 整合性チェック | 手札・状況文から**犯人が推理できるか**、**捏造カードが他のカードとの矛盾から見破れるか**、結末文との矛盾がないかをAIが判定 | 指摘内容を表示。修正して再実行 |
| 不適切表現チェック | 過度な残虐描写、性的表現、実在の人物・団体への誹謗、差別的表現 | 公開不可。該当箇所を指摘 |

- 整合性チェックは**助言レベル**とし、判定が「疑義あり」の場合でも、投稿者が理解した上で公開を選べる。ただし不適切表現チェックは必須。

## 7. プレイ・マッチング仕様

### 7.1 プレイの開始方法

1. ホームで「ミステリーであそぶ」を選択。
2. 未プレイのシナリオ一覧から1つ選ぶ。
3. **何人で遊ぶか（1〜4人）**を選ぶ。1人を選ぶと、他の3席は最初からNPCになる。
4. 2〜4人を選んだ場合は、**同じシナリオ・同じ人数指定で待っている人**と組み合わせる。

### 7.2 マッチングと待機

- 待機中は、集まった人数と残りを表示する。
- **待機時間の上限は90秒**【仮】。上限になった時点で、**不足分をNPCで補って開始**する。
- 待機中に、「今すぐNPCで開始」を選ぶこともできる（参加者が1人でも可）。
- 同じシナリオを**すでにプレイ済みの人**はマッチングされない。

### 7.3 プレイ済みの扱い

- シナリオが「プレイ済み」となる条件：**ゲームの確認フェーズに入った時点**。
  - 途中離脱でも、真相の一部を知った可能性があるため、再挑戦は不可とする。
- プレイ済みのシナリオは、シナリオ選択画面に表示しない。
- 自分が投稿したシナリオは、**投稿者自身はプレイ不可**（真相を知っているため）。

### 7.4 NPCの表示

- ルーム内で、各席に「人間」または「NPC」の表示を付ける。
- 席が途中でNPCに切り替わった場合は、チャットに「○○がNPCに切り替わりました」と表示する。
- 名前はキャラクター名で表示し、プレイヤー名は出さない（匿名性の確保）。ただし、NPC・人間の区別は表示する。

### 7.5 再接続（F13）

- 切断後、5.4の無操作時間内に再接続すれば、元の席に復帰できる。
- 復帰時は、これまでのチャットと公開済みカードを再表示する。タイマーは、サーバー時刻を基準とする。

## 8. アカウント・プレイ履歴

### 8.1 アカウント
- 表示名（ルーム内ではキャラクター名を使用するため、主に履歴・マイページ用）。
- 年齢確認：登録時に**13歳以上**であることを同意させる【仮】。

### 8.2 プレイ履歴
- プレイしたシナリオ（プレイ済みの管理）、日時、担当キャラクター、犯人役だったか、勝敗。

### 8.3 勝敗の記録
- 通常終了：勝敗を記録。
- NPCに切り替わった席：「離脱」として記録し、勝敗には含めない。

## 9. 通報・モデレーション

- シナリオ（G05の詳細・G09の結果画面）に**通報ボタン**を設ける。理由：不適切な内容／整合性不備／その他。
- 同一シナリオへの通報が**3件（異なるユーザー）**【仮】に達すると、**自動的に非公開**にし、運営が確認する。
- 運営は、管理画面で「非公開の継続」「復帰」「投稿者への警告・停止」を選ぶ。
- 通報の悪用を防ぐため、1ユーザーが1シナリオに通報できるのは1回のみ。
- チャット内の不適切発言：禁止ワードの自動マスクと、プレイヤー単位の通報。繰り返す場合は運営がアカウントを停止する。

## 10. 非機能要件

| 項目 | 内容【仮】 |
|---|---|
| 対応環境 | 最新2バージョンの Chrome / Safari / Edge / Firefox。PC・スマートフォン |
| 同時ルーム数 | 公開時は100ルーム（400人）を想定。増加に対応できる構成とする |
| 応答 | チャット反映は1秒以内。NPCの発言生成は10秒以内（超える場合は短い待機表現を挟む） |
| 可用性 | 進行中ルームの状態はサーバーに保持し、サーバー再起動後も復旧できること |
| セキュリティ | 他プレイヤーの状況文・非公開手札は、**サーバーからクライアントに送信しない**。通信はHTTPS／WSS |
| AIコスト | 1ゲームあたりのAI費用の上限を設定し、超過しそうな場合は発言頻度を下げる |
| プライバシー | 個人情報は最小限。チャットログはシナリオ改善・通報対応のため一定期間保存【仮：90日】 |
| アクセシビリティ | 文字サイズ変更、十分なコントラスト、キーボード操作 |
| 言語 | 日本語のみ |

## 11. 対象外（今回のスコープ外）

- 音声・動画チャット
- 5人以上、または3人以下のキャラクターを持つシナリオ
- 非公開のささやきチャット
- 評価・レビュー、ランキング、称号
- 年齢区分の分離、有料課金・シナリオ販売
- 公開後のシナリオ本文の編集
- 英語など他言語
